# WallsPaper

An interactive wallpaper gallery built with HTML, CSS, and JavaScript.

## Project structure

- `html/` — page markup
- `css/` — styles
- `js/` — gallery interactions
- `index.html` — root entry point for GitHub Pages

## Run locally

Open `index.html` in a browser, or serve this folder with a local static web server.

Wallpaper photos are served by Unsplash, so an internet connection is needed to load them.

## Publish with GitHub Pages

This project is configured to publish from the repository root. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The root page redirects visitors to `html/`.
